Why is CSS referred to as Cascading?

As the PowerPoint analogy from our earlier online discussion suggests, it is cascading because of how the design takes effect. It applies the style like a "cascading" waterfall, drawing from multiple sources and flowing downward in a specific order of priority. For example, I applied a background color style to the body tag, which in turn affected the entire webpage background, but then I decided to change the background color of elements to surround the text in a box pattern.

Different Types of CSS

There are three main ways to apply CSS to an HTML document, along with the @import rule. They differ based on where the style rules are written and how they are linked to the HTML, which determines their priority and reusability.

Inline CSS

This is applied directly to a specific HTML element using the style attribute. This is mostly used for quick, singe-element styling and has the highest priority

Example: <body style="font-family: Jua; background-color: #d1f5c4;">

Internal CSS

These are defined inside a <style> tag inside the <head> section of the HTML document. These are mostly used to style a specific webpage.

Example: <style> body {color: #48653e;} </style>

External CSS

This is an alternative way to import an external stylesheet from within another CSS file or the HTML head.

Example: <link rel="stylesheet" href="styles.css">

Different Types of Selectors

CSS selectors are used to "find" (or select) the HTML elements you want to style.

Element Selector

This only selects HTML elements based on their tag name.

Example: p { text-align: justify; margin: 0px; padding: 0px; }

ID Selector

This uses the id attribute of an HTML element that select a specific, unique element.

Example: #me { background: linear-gradient(to right, #48653e, #ddbf44); -webkit-background-clip: text; background-clip: text; -webkit-text-fill-color: transparent; color: transparent; }

Class Selector

This selects HTML elements with a specific class attribute.

Example: .example-box { background-color: #d3d8d1; border-radius: 3.5px; padding: 9.5px; margin-top: 3px; }

Universal Selector

This selects all HTML elements on the page.

Example: * {color: #48653e;}
